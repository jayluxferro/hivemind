# SPEC: HiveMind SQLite → PostgreSQL migration (lattice-style)

Contract for migrating `src/hivemind/storage/db.py` from aiosqlite to PostgreSQL with
psycopg3, mirroring the sibling project lattice's pattern. Approved plan:
`/Users/jay/.claude/plans/happy-dazzling-lampson.md`. Implement against this spec;
deviate only for a verified reason and note it in the summary.

## Environment (already provisioned)

- Local Postgres 17 on `localhost:5432`, superuser `postgres` (socket trust).
- Role `hivemind` (LOGIN) created; databases `hivemind` and `hivemind_test` created, owner `hivemind`.
- Loopback is trust auth (`host all all 127.0.0.1/32 trust`) — no password needed locally.

## Contract

### 1. `pyproject.toml`

- Remove `aiosqlite>=0.20.0`; add `psycopg[binary]>=3.2`. Run `uv lock`.

### 2. `src/hivemind/storage/db.py` — full rewrite (async psycopg)

- `SCHEMA_VERSION = 1`; `_MIGRATIONS: dict[int, Callable] = {1: _migration_v1}` where
  `_migration_v1(conn: psycopg.AsyncConnection) -> None` is an `async def` executing the DDL
  below statement-by-statement (no parameters in DDL; all idempotent `IF NOT EXISTS`).
- `class Database`:
  - `def __init__(self, db_url: str = "postgresql://hivemind@localhost:5432/hivemind")`
  - `async def connect(self)` — `psycopg.AsyncConnection.connect(self.db_url, row_factory=dict_row)`,
    `await conn.set_autocommit(True)` (NOT `conn.autocommit = True` — assignment raises on
    AsyncConnection), then `await self._apply_migrations()`.
  - `async def close(self)`; `@property def db(self) -> psycopg.AsyncConnection` (raise
    RuntimeError if not connected — keep current contract).
  - `async def _apply_migrations(self)` — lattice runner: ensure
    `schema_migrations (version INTEGER PRIMARY KEY, applied_at BIGINT NOT NULL)`, read applied
    versions, for each unapplied migration in order: `await cur.execute("BEGIN")` → migration →
    `INSERT INTO schema_migrations (version, applied_at) VALUES (%s, %s)` with
    `int(time.time()*1000)` → `COMMIT`; `ROLLBACK` + re-raise on exception.
  - `async def applied_versions(self) -> list[int]` — for tests/importer.
- All 12 existing method signatures unchanged (insert_task, update_task, get_task, list_tasks,
  count_tasks_by_state, insert_metrics, get_agent_metrics, log_request, get_aggregate_stats,
  reset, connect, close). `?` → `%s` everywhere. `row["col"]` access stays (dict_row satisfies
  it — verified every row access is named-only).
- JSONB: writes `json.dumps(x)` + `%s::jsonb` cast; reads via `_maybe_json(value, default)`
  helper (returns value as-is if dict/list, `json.loads` if str, default on None/""/error).
  Use it in `_row_to_task` for `dependencies`/`metadata` only.
- `await self.db.commit()` after writes stays verbatim (safe no-op under autocommit).
- `reset()` → `TRUNCATE tasks, agent_metrics, request_log` + commit.
- Docstring: Postgres backend, one async connection, autocommit keeps the sqlite contract,
  fail-loud when PG is down (no fallback), versioned idempotent migrations.

Migration v1 DDL (exact):

```sql
CREATE TABLE IF NOT EXISTS tasks (
    id               TEXT PRIMARY KEY,
    command          TEXT NOT NULL,
    state            TEXT NOT NULL DEFAULT 'pending',
    priority         INTEGER NOT NULL DEFAULT 1,
    token_budget     INTEGER,
    tokens_used      INTEGER NOT NULL DEFAULT 0,
    dependencies     JSONB NOT NULL DEFAULT '[]',
    estimated_tokens INTEGER,
    created_at       DOUBLE PRECISION NOT NULL,
    started_at       DOUBLE PRECISION,
    completed_at     DOUBLE PRECISION,
    agent_id         TEXT,
    error            TEXT,
    result           TEXT,
    checkpoint_path  TEXT,
    metadata         JSONB NOT NULL DEFAULT '{}'
);
CREATE INDEX IF NOT EXISTS idx_tasks_state ON tasks(state);
CREATE INDEX IF NOT EXISTS idx_tasks_priority ON tasks(priority DESC, created_at ASC);

CREATE TABLE IF NOT EXISTS agent_metrics (
    id               BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    agent_id         TEXT NOT NULL,
    task_id          TEXT NOT NULL,
    tokens_in        INTEGER NOT NULL DEFAULT 0,
    tokens_out       INTEGER NOT NULL DEFAULT 0,
    requests_made    INTEGER NOT NULL DEFAULT 0,
    requests_failed  INTEGER NOT NULL DEFAULT 0,
    retries          INTEGER NOT NULL DEFAULT 0,
    avg_latency_ms   DOUBLE PRECISION NOT NULL DEFAULT 0.0,
    recorded_at      DOUBLE PRECISION NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_metrics_agent ON agent_metrics(agent_id);

CREATE TABLE IF NOT EXISTS request_log (
    id               BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    agent_id         TEXT,
    method           TEXT NOT NULL,
    path             TEXT NOT NULL,
    status_code      INTEGER,
    tokens_in        INTEGER NOT NULL DEFAULT 0,
    tokens_out       INTEGER NOT NULL DEFAULT 0,
    latency_ms       DOUBLE PRECISION NOT NULL DEFAULT 0.0,
    retried          INTEGER NOT NULL DEFAULT 0,
    error            TEXT,
    recorded_at      DOUBLE PRECISION NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_request_log_agent ON request_log(agent_id);
CREATE INDEX IF NOT EXISTS idx_request_log_time ON request_log(recorded_at);
```

No FOREIGN KEYs (sqlite schema had none — no behavior change). Timestamps stay
`DOUBLE PRECISION` floats (models use `time.time()` floats; doubles round-trip bit-exact).

### 10. `tools/pg-migrate/import_sqlite.py` — NEW

Modeled on lattice's `tools/pg-migrate/import_sqlite.py` (stdlib sqlite3 read + psycopg write).

- Args: `--src` (default `./hivemind.db`), `--dsn`
  (default `postgresql://hivemind@localhost:5432/hivemind`), `--fresh` (default) /
  `--no-fresh`, `--dry-run`.
- Dry run: read-only sqlite counts + read-only target counts + plan; touches nothing
  (migrations NOT applied). Real import:
  1. Open sqlite read-only (`sqlite3.connect(f"file:{src}?mode=ro", uri=True)`).
  2. Open async target via `hivemind.storage.db.Database(args.dsn)` + `await connect()`
     (migration v1 applies).
  3. `--fresh`: `TRUNCATE tasks, agent_metrics, request_log RESTART IDENTITY`;
     `--no-fresh`: skip tables that already have rows (report).
  4. Guard: fail if `dependencies`/`metadata` contain empty/whitespace strings
     (uncastable to jsonb) — check before COPY.
  5. `_assert_schemas_align`: sqlite `PRAGMA table_info` column names+order must equal PG
     `information_schema.columns` order — fail loudly on drift.
  6. COPY per table `FROM STDIN WITH (FORMAT csv)` in order tasks → agent_metrics →
     request_log: `async with conn.cursor().copy(sql) as copy: await copy.write(line)` per row.
     CSV bytes: unquoted empty field = NULL; non-null fields quoted, `"` doubled; INTEGER →
     `str(int(v))`; REAL → `repr(float(v))`; TEXT/JSON passthrough as stored text (sqlite
     wrote valid JSON via json.dumps).
  7. Sequence fix (VERIFIED necessary — explicit identity inserts don't advance sequences):
     `SELECT setval(pg_get_serial_sequence('agent_metrics','id'), (SELECT MAX(id) FROM agent_metrics))`
     and same for `request_log`.
  8. Verification: per-table sqlite-vs-PG counts equal; exit 1 on mismatch; print summary.
- Empty source: COPY of zero rows, counts 0 == 0 — works trivially.
- Docstring mirrors lattice's importer style (sources, strategy, idempotency, verification).
